## 📌 Project Overview

**Smart Personal Expense Classifier** is a machine learning-based application designed to automatically categorize personal expenses into different spending categories.

The application helps users organize their expenses, analyze spending patterns, and generate category-wise spending summaries for better financial management.

It uses machine learning and data processing techniques to simplify manual expense classification.

## 🎯 Objectives

- Automate personal expense categorization.
- Reduce manual effort in managing expenses.
- Organize expenses into meaningful categories.
- Analyze spending patterns.
- Generate category-wise expense summaries.
- Help users monitor their budgets effectively.

## 📊 Expected Outcome

The application automatically organizes personal expenses into seven categories and generates spending summaries, helping users understand their expenses and make better budgeting decisions.

✨ Key Features

-🤖 Automatic Expense Classification: Uses machine learning to categorize personal expenses.
-📊 Interactive Expense Dashboard: Displays expense information and financial summaries.
-📅 Monthly & Yearly Reports: Tracks spending over different periods.
-📈 Expense Visualization: Uses charts to represent spending patterns.
-💰 Budget Planning & Notifications: Helps users plan budgets and monitor expenses.-
-🧠 Machine Learning Classification: Automatically predicts expense categories-.
-📄 PDF & Excel Export: Allows users to export expense reports.
-🔐 User Authentication: Supports secure user account access.
-📁 Personalized Expense History: Maintains individual expense records.
-🗂️ Seven Expense Categories: Food, Travel, Shopping, Bills, Entertainment, Recharge, and Others.

## 📂 Expense Categories

The application supports seven expense categories:

1. 🍔 Food
2. 🚗 Travel / Transportation
3. 🛍️ Shopping
4. 💡 Bills / Utilities
5. 🎬 Entertainment
6. 📱 Recharge
7. 📌 Others

## ⚙️ How It Works

1. User enters an expense description and relevant expense details.
2. The application processes the expense information.
3. Machine learning techniques classify the expense into a suitable category.
4. The expense is organized under the predicted category.
5. Category-wise summaries help users understand their spending patterns.

## 🚀 Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/smart-expense-classifier.git
```

### 2. Navigate to the Project Directory

```bash
cd smart-expense-classifier
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

**Mac/Linux:**

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

### 7. Open in Browser

```text
http://127.0.0.1:5000/
```
